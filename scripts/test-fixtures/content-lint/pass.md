# Magnesium verstehen

Magnesium unterstützt normale Körperfunktionen. Eine Referenzmenge kann zum Beispiel 300 mg nennen.

## Wofür der Körper Magnesium nutzt

Der Mineralstoff ist an vielen Abläufen beteiligt.
